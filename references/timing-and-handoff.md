# 时间、配音入口与项目交接

这是原文之外的用户定制执行接口。保留 X 01、飞书编排 2.0 与 ChatCut 2.0 原文件。

## 三种时间

- **真实发声**：保存原始 ASR 及按定稿核对的短语/词时间，允许真实静音存在。只用识别时间，不按字符数摊分时长。识别错字可按定稿纠正；实际漏读或误读要处理音频，不能仅替换字幕。
- **连续编排**：另写 `audio/vo-align.txt`，供原文分镜与节拍点使用。首段从 0 开始，末段到音频实际结束。相邻发声区间有间隙时，取间隙中点作为共享边界，保留推导关系。原始发声记录不被这份连续表覆盖；异常重叠/负时长先复核。
- **镜头内部动作**：为换图、选中、连线或结果出现绑定唯一短语/词 ID，记录全片毫秒、镜头内相对毫秒和帧值。动作落在所属镜头内，不能只写“第一次/第二次变化”而缺少触发依据。

字幕依据真实发声表；为阅读延长停留属于独立字幕显示决定，记录调整区间，不把它当作真实发声。镜头起止、节拍点与所有素材共享[ChatCut 毫秒转帧规则](chatcut-workflow.md#毫秒与帧的接口)。动作锚点也使用同一帧率；不同边界量化成同一帧时先复核切分，不悄悄挪动边界。

## 配音调用入口

已有音频直接采用，记录路径、时长、格式和对应定稿；不擅自换音色或重新合成。文案起步时，新配音按下方 1.15 倍默认速度，音色、调用入口及费用沿用本项目有效选择，不带入其他角色项目的设置。

用户选择豆包时，使用下方直接入口。当前 hosted ChatCut 的 `manage_voice` / `submit_voice` 是另一条会消耗 ChatCut 积分的路线，仅在用户选择并授权时采用。保留 X 01 的整段一次合成，不采用通用 voice Skill 的分句合成建议。

记录一次生成的文本版本、音色、参数、任务 ID 和状态；成功音频复用，失败或超时先核对任务。结果未知标为 `uncertain`，不自动重发造成重复计费。导入或下载成功后保留源音频。若返回格式不同于 X 01 的 44100 Hz 单声道 WAV，明确记录实际规格，作必要格式转换且保留源文件，不隐式变速或剪掉静音。

Whisper large-v3 的环境与模型就绪后，先检查识别输出再对齐定稿，保存真实时间和连续时间两份记录。没有音频、对齐异常或原稿漏读未解决时，不把计划时长写成已测得值。

### 默认配音速度

本工作流新合成豆包配音默认采用 **1.15 倍速**。在合成阶段设置 `speed_ratio=1.15`、V3 整数参数 `speech_rate=15`；合成后按实际音频完成声学对齐、字幕和分镜，不给成片再叠加一次加速。

配音节奏优先于样片的目标秒数，不为凑够时长自动放慢声音。已有音频和成片保留原速；用户要求重做时另存版本并重新对齐。用户明确指定其他速度时，以新指令为准。

### 豆包直接入口

每位使用者提供自己的配置。默认读取 `~/.config/line-figure-knowledge-video/doubao-tts.json`，可用 `--config` 指定其他位置，或通过 `DOUBAO_TTS_API_KEY` 环境变量提供密钥。格式见 [配置示例](../config/doubao-tts.example.json)。Unix 系统的密钥文件权限应为 0600；不要输出密钥或将真实配置提交到仓库。

使用 [synthesize_doubao.py](../scripts/synthesize_doubao.py)，依赖 Python 3 与 `httpx`。脚本默认只打印安全参数预览；在已有生成授权后加 `--synthesize` 发送一次全文请求：

```bash
python3 scripts/synthesize_doubao.py \
  --script /项目/口播定稿.txt --output /项目/audio \
  --speaker zh_male_liufei_uranus_bigtts --speech-rate 15 --synthesize
```

音色由本项目明确传入，示例音色仅供字段示范，实际以账户可用音色为准。脚本的 `speech-rate` 默认值为 15，示例也明确写出该值。倍率按 `round((speed_ratio - 1) * 100)` 映射到当前 V3 参数，1.15 对应 15。接口为 `https://openspeech.bytedance.com/api/v3/tts/unidirectional/sse`，资源 `seed-tts-2.0`。字段依据[字节跳动 V3 示例](https://github.com/bytedance/agentkit-samples/blob/main/skills/byted-text-to-speech/scripts/text_to_speech.py)核对；接口变化时重新核实。

输出原始 PCM、44100 Hz 单声道 `vo-full.wav`、安全请求参数和 `tts-attempt.json`。脚本在联网前创建排他请求记录，已有记录或音频时拒绝重复执行；`uncertain` 先调查结果，不删除记录来强行重发。预览不读取密钥、不联网。

入口源于已完成的动作样片调用；其他使用者需要自己的服务凭据、可用音色和权限，不能沿用原制作者的账户授权。通用脚本的修改用离线预览验证，不为测试重复付费合成。

配音经过变速或剪辑，另存版本并重新声学对齐，不能只按倍率缩放旧时间戳。Whisper 时间边界有疑问时，保留原结果，采用独立识别或人工核对复核，注明最终时间来源。

## 一份项目记录

使用项目自己的 `project-state.json` 或等价简短清单，引用现有文件即可，不复制全文：

- 定稿、音频、声学表、连续表、九列表和节拍点的路径与版本/哈希；
- 已选动作方式、画布帧率、字体、字幕方案；
- 每镜的状态图或图形资产、输入版本、云端 assetId 与 itemId；
- ChatCut projectId、timelineId、工程链接；
- 生成、上轨、静帧检查、连续播放、回听和导出各自的真实状态；
- 付费任务状态、已知问题、受影响镜头与下一步。

续做先查看记录，再核对实时工程。文案或音频变化时，只重新处理受影响的对齐、动作和素材；不能把本地清单视为云端工程现状的证明。

## 交付与证明范围

可编辑工程链接、源素材、本地工程包和 MP4 分别列出。NLE 包可能保留剪辑但把 MG 渲染成视频，导出前检查当前能力并说明限制；不声称与原生 ChatCut 属性编辑等价。用户要求本地可移交工程时，交付支持的格式与所需素材，并记录原生资产信息；未实际导出的包不得列为已交付。

原文校验、素材就绪、时间轴结构、合成静帧、连续播放和回听分别提供证据。未完成的检查直接标明；八段原文校验通过不证明视听样片通过。

本地辅助工具的输入格式和命令见 [local-tools.md](local-tools.md)。项目备份需保存 MG 最终实例参数和每项本地素材的实际取得状态，按 [字幕与交付检查](captions-and-delivery.md)逐项核对。
