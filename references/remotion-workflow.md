# Remotion 默认制作流程

后续线条小人视频使用 Remotion。现有旧工程是否迁移按用户范围判断，不自动重做已交付视频。

## 本地风格工程

优先复用当前工作区或项目记录中的 Remotion 工程。本机常用候选为 `~/Documents/线条小人/remotion-line-figure`；先核对实际存在与项目说明，再读取其风格、动作、组件、入口及已完成剧集目录。复用色彩、字体、构图与动作节奏，为新一期新增独立目录和 Composition，不覆盖以前的片子。

此路径是本机现有工程，不假定其他安装环境都有。缺失时使用当前可用的 Remotion 创建技能建立工程，沿用本包角色与视觉规范；不自动退回 ChatCut。

## 制作与验证

- 加载当前 Remotion 入口技能，按任务读取创建、markup、字幕、Studio 和导出说明；以实际安装依赖为准，不为普通制作升级依赖。
- 原有定稿、配音、ASR、声学短语、字幕和图像按已确认记录复用。需要新付费素材时只在授权范围内调用。
- 分镜按[叙事与动作设计](visual-storytelling.md)区分场景演绎与干货讲解。实际制作先完成能代表本期难点的 A-roll 与 B-roll 动作段，检查动作可读、知识关系成立和前后承接，再复用到同类镜头；已授权整片时内部检查后继续，不逐镜等待确认。
- B-roll 使用可编辑 React/SVG 图形、文字和时间参数，按[整组随口播出现](broll-editable.md#整组随口播出现)绑定真实词/短语锚点。框线、文字、数值、底条和相关连线由同一组控制可见性；SVG 与 HTML 元素分开实现时，也共享该组锚点。仅给数值或彩色柱加动画会留下提前出现的框、名称和底条，须一并处理。包内 ChatCut JSX 模板可作布局参考，不假定可直接运行；记录实际改写与来源。
- B-roll 在整组出现控制之上实现所需的对象联动：可用稳定对象 ID 和共享状态参数保持图形、图片、标注及连线的对应关系，按讲解呈现移动、比较、筛选、拆解或结果变化。真实素材保持独立，头像不替代主体讲解。
- A-roll 用独立关键状态图表现人物处境、行动、反应与结果，换图绑定真实口播，保持物件连续与结果停留。旁白、BGM、音效和字幕均保留独立控制。按实际素材来源和完整性记录，不拿扁平 MP4 包装成可编辑工程。
- 字幕按 [字幕切分与显示](captions-and-delivery.md#字幕切分与显示) 制作：完整语义换屏、去显示标点、每屏一行，短停顿和跨镜接续显示。旁白贯穿全片时让字幕跟随旁白时间轴；单镜实例按实际区间相交，避免换行或原文位置导致漏句。核对实际宽度及[字幕连续性](captions-and-delivery.md#字幕连续性检查)。
- 使用已有工程的检查命令验证；在 Studio 或渲染帧中检查文字、布局、动作过程和声音。按[叙事与动作检查](captions-and-delivery.md#叙事与动作检查)验证场景演绎和联动讲解；逐项图解按[逐项出现检查](captions-and-delivery.md#逐项出现检查)核对各组入场前后及中间阶段，不能只看最终布局。用户明确要求导出时，用 Remotion 导出 MP4，核对真实文件、完整解码，并从编码后的成片复核对应出现节点。
- 分别记录抽帧、播放、连续观看、连续回听和导出状态。
- 交付源代码、配置、素材清单、依赖锁文件、MP4、SRT 和按需封面。打包不包含 node_modules、密钥或浏览器凭据。

封面仍按 `covers.md` 独立生成 3:4 与 4:3，视频引擎切换不改变角色和封面规范。
