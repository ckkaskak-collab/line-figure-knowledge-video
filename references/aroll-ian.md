# A-roll 角色与动作接口

这是本工作流的角色制作接口，不是 X 或飞书提示词原文。Ian 风格参考已内置于 `illustration/`，不需要安装另一份 Skill。默认身份以 [包内原图](../assets/character/reference.jpg) 为准；项目明确指定自有角色时，以该项目参考和身份说明覆盖默认角色。

## 传入上下文

把定稿全文作为背景，并为当前 A-roll 提供：

- 分镜整行，包括镜头号、时间、配音、画面设计、动态变化、衔接；
- 本镜要表达的意思和人物动作、物件、结果状态；
- 已有的前后镜头、视觉选择与本次实际请求的输出数量；
- 本镜动作状态表：状态编号、对应定稿短语及唯一短语 ID、手与道具发生的变化、需要锁定的机位/景别/位置、状态图路径；有实际音频时同时填写全片毫秒、镜头内相对毫秒和共享帧边界。

已有分镜时，按本次选中的 A-roll 镜头生成，不把 Ian 的文章默认 4–8 张直接当作视频镜头总数。镜头时长来自已给时间轴，Ian 只负责所需图像与配图方案，不重新估算时间或修改配音文案。

## 图像生成

1. 每张新图读取 [角色说明](illustration/character-ip.md)、[生图模板](illustration/prompt-template.md)；首次制作同时读取 [风格](illustration/style-dna.md) 和 [构图](illustration/composition-patterns.md)。这些是本包文件，不从宿主查找同名 Skill。
2. 每张生图前查看并传入项目选定的角色原图；未另行指定时使用[默认角色原图](../assets/character/reference.jpg)。将选定原图的绝对路径作为 `image_gen.referenced_image_paths`。只借用身份，动作和构图按当前镜头重新设计。
3. 图像保留 Ian 的白底、黑色手绘线稿、克制的红橙蓝批注与留白。线条小人参与核心动作；不使用其上游案例角色替代用户 IP。
4. 生成后执行 [图像 QA](illustration/qa-checklist.md)，保存到项目的 `assets/aroll/`。记录图片对应的镜头号，文件名可带 `S001` 等镜头前缀方便后续剪辑。只交方案时不声称已生成图片。

默认不同时注入 X 的 04/05，避免三类参考、虚化场景等原路线要求与 Ian 当前的白底风格互相覆盖。需要重回作者原路线时，依据用户明确选择单独调用，原文档案保持不变。

## 与 B-roll 的边界

Ian 对真实 UI、正式图表、PPT 等限制约束它生成的 A-roll 图片，不直接扩展到 B-roll。知识关系图、真实截图与录屏仍可按 B-roll 需要准备。

## 已选动作方式：关键状态图切换

本工作流默认采用关键状态图切换，必要时少量推近。每个状态必须让观众看见新的处境、行动或结果；张数由内容决定，不平均分配时长，不强凑三张。镜头超过 8 秒时仍按编排原文安排有效信息变化，整图缩放、呼吸和入场不替代人物行动。

1. 先写“本镜目标 → 起始状态 → 必要变化 → 结果”，为每次变化绑定定稿短语。没有真实音频时只做动作方案和素材准备，不编造毫秒时间。
2. 首张图通过 Ian QA 后作为本镜基准。后续图继续传入用户原图和已通过的基准图，明确各图角色身份/场景/编辑目标的作用；锁定机位、景别、画面方向、角色比例与未变化道具，只改变当前动作。每张独立输出，不用一张多格漫画替代多张状态素材。
3. 手、姿态、视线和道具表达反应，保留项目选定角色的五官等身份特征（默认角色无明显嘴巴）。检查持笔手、物件数量和放置位置的前后连续性；需要跳过中间动作时，下一状态仍须易于理解。
4. 每张图作为独立时间轴素材放入本镜区间。首张建立处境，后续换图对应真实短语/词锚点，保持到下一次有效变化或镜头结束。推近仅用于强调，不遮挡动作道具或字幕。
5. 状态切换不足以表达关键过程时，再根据本镜需求考虑分层局部动画或连续视频；不自动推广到整片。连续生成先核对实际工具与费用。

时间交接采用[时间与项目交接](timing-and-handoff.md)。检查时既看各状态的身份与构图，也看换图前后帧及完整动作段；素材生成成功不是动作实现通过。
