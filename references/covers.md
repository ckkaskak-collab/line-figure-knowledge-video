# 按需制作线条小人封面

只有用户请求封面时使用本分支，不为每次视频任务自动增加生图。

1. 从正文提炼一个准确且可读的标题；正文只提出趋势或问题时，封面也保留不确定性。确定本次所需比例。
2. 查看并传入项目选定角色原图，参考 [角色说明](illustration/character-ip.md)。封面默认白底、炭黑手绘、蓝色重点和少量暖橙，角色参与具体行动。
3. 3:4 竖版与 4:3 横版各自设计布局并独立生成，不用裁切或拉伸互相转换。大标题与封面比例覆盖正文插图默认 16:9 和标题限制；不要把这些覆盖扩散到视频正文。
4. 竖版可以上标题、下动作，横版可以标题与人物并置。根据内容调整，不固定复制旧片的手机、键盘或标注。
5. 验证实际像素尺寸、比例、汉字、缩略图可读性、安全边距和角色一致性；记录生成参考、提示词、路径和哈希。提示词要求的比例不等于文件实际比例。

界面概念插画属于示意，不用来证明产品功能。需要真实界面的封面时采用真实素材，保持其事实内容。
