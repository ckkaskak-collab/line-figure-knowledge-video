# B-roll 圆形讲解头像

本工作流默认在 B-roll 显示圆形角色头像，右侧放射音量条跟随旁白。A-roll 不显示；用户明确关闭或改变位置时按本次要求执行。

## 头像与构图

- 默认角色可复用[已确认的头部素材](../assets/character/speaker-head-right.png)。它由内置 image_gen 参考包内角色原图生成，仅作为头像，不替换 A-roll 角色原图。项目指定其他角色时重新制作对应头部，不能混用身份。
- 左下角头像朝右、面向画面内侧；保持头部竖直、双眼清楚。换到右侧时相应调整朝向。避免低头或朝画面外。
- 圆框必须容纳完整头发、耳朵、脸颊及下巴，头部在圈内居中，轮廓与框线之间有白边。优先使用专用头部图和 `objectFit: contain`；不要从全身图放大偏移硬裁而切掉脸部。不要靠只缩小脸、留下过大头发来凑圆框。
- 1920×1080 可从圆心 (116, 850)、直径约 138 px 起步；这是布局起点，不是每片固定坐标。连同音量条最大伸展范围一起检查，与字幕上缘和内容边界留空。其他尺寸按画布重新布局。
- 白底、炭黑圈线、柔和蓝音量条。保持既有竖线眼和无明显嘴巴的角色特征，不因参考视频有嘴型就自动增加五官。

## 音量条与时间

- 使用干净旁白分析音量或频带，不能由 BGM、随机数或无关循环驱动。参考形式是右侧约七根圆头放射短线，声音强时伸长、加深，停顿时回落；数量和幅度可随画面微调。
- 可在 Remotion 读取音频，也可离线预计算逐帧强度。预计算时保存音频哈希、采样率、帧率、帧数、归一化和静音门限；配音或剪辑变化后重新分析。
- 已验证的一种实现：2048 点 Hann 窗 FFT、七个频带、各频带百分位归一化、静音门限与快速起伏平滑。算法参数是参考，不把当前片子的频带结果复制到下一片。
- 传入整片帧号：`episodeFrame = shotStartFrame + localFrame`。有音频偏移、裁切或变速时按实际时间映射取值。单镜预览与完整时间线应得到相同的声音强度，不能每个镜头重新从人声第 0 秒开始。
- 组件只在 B-roll 分支或明确的 B-roll 帧区间内加载；A-roll 分支提前返回。头像、圈线和音量条保留独立可编辑的图片路径、位置、尺寸、颜色与幅度。

## 检查

先看头像放大图，再看整帧：完整头部、朝向、圈内留白都正确；检查说话与停顿的连续帧，以及音量条最长时与图解、字幕的距离。抽查 A/B 切换前后，确认 A-roll 不残留头像。

只改头像时保留旁白、字幕及其他镜头；渲染前后可对比 A-roll 抽样帧和导出音轨。核验编码后的 MP4，分别记录抽帧、完整解码和实际连续观看/听审，不能互相代替。
