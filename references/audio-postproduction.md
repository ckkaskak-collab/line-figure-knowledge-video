# 配乐与音效

先读取项目已有选曲和用户要求。沿用已确认素材；需要新选曲时根据内容与旁白节奏提供适量候选或在已授权范围内直接选定，不机械增加确认环节。

- 每个候选记录标题、作者、来源、取得日期、许可/署名要求和本地路径。试听文件标明是否剪辑过，不能把下载失败写为素材已经取得。
- 优先选择适合片长的素材；短循环需要检查每个接缝。音乐覆盖片长、开头淡入、结尾淡出，人声段适度压低音乐，参数以实际听感为准。
- 音效用于有意义的动作或信息变化，避免每个字或图形都发声。检查峰值、重复疲劳及与旁白冲突。
- 仅替换配乐时复用当前画面、人声、字幕和时点；记录替换前状态以及新素材、轨道、音量、淡变和覆盖范围。
- 在实际播放器连续回听人声、音乐和音效，特别检查循环接缝和首尾。响度计算、解码成功和静态波形不构成听感验收。
- 新增外部生成前核对服务、计费和本次授权。使用自己的授权素材或公开可用素材，不把别的项目的歌曲变成所有视频默认曲。

交付保留声音原文件及必要署名，记录裁剪、循环、音量或淡变等处理。只能取得云端 ID 时列为备份缺项。
